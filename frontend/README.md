# Auto Auctioneer System frontend

This frontend is a self-contained React + TypeScript application built with Vite and Tailwind CSS.

## Development

To work locally, install Node.js and npm, then run:

```sh
git clone <this-repository-url>
cd <repository-name>/frontend
npm install
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
